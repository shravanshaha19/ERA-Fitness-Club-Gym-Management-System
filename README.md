# 🏋️ ERA Fitness Club – Gym Management System

A responsive and user-friendly **Gym Management System** developed using **PHP, MySQL, HTML, CSS, and JavaScript**.  
This project is designed to help fitness clubs and gyms manage memberships, trainer information, fitness packages, and user interactions through a modern web-based platform.

---

# 📌 Project Overview

ERA Fitness Club is a web application created to simplify gym management and improve user experience for members and visitors.  
The system provides an interactive platform where users can register, log in, explore fitness services, view trainers, choose membership packages, and contact the fitness club easily.

The project focuses on creating a clean, responsive, and efficient digital solution for fitness centers.

---

# 🚀 Features

## 👤 User Authentication
- User Registration
- Secure Login System
- Session Management
- Logout Functionality

## 🏋️ Fitness Services
- Gym Information
- Yoga Sessions
- Aerobics Programs
- Personal Training Details

## 📅 Membership Management
- Membership Package Selection
- Registration Forms
- Membership Status Tracking

## 👨‍🏫 Trainer Management
- Trainer Profiles
- Trainer Information Display

## 📞 Contact & Feedback
- Contact Form
- Feedback Submission
- User Inquiry System

## 💻 Responsive Design
- Mobile-Friendly Interface
- Works on Desktop and Laptop
- Modern UI Design
